E' un [[Tipologia di attacchi |tipologia di attacco]] in cui un gruppo di persone cerca delle **vulnerabilità** di un sistema informatico. 

1. **[[1) Scansione]]** -> Facile
2. **[[2) Enumerazione]]** -> Facile
3. **[[3) Exploitation]]** -> Media
4. **[[4) Privilege Escalation]]** -> Difficile
5. **(opzionale) Post Exploitation** -> Media
   

E' presente una **macchina attaccante** ed una **rete interna bersaglio** collegato ad una macchina.

La Macchina bersaglio si espone con un indirizzo **IP pubblico** a cui puntare ed un **indirizzo IP Privato**. Eventualmente questa macchina potrebbe essere connessa ad altre rete interne.
La maggior parte delle volte, l'attacco si ferma alla macchina principale e spesso è superfluo attaccare le reti locali ([[Pivoting]]).
