È un **sistema di vulnerability scanning**, ovvero analizza i server alla ricerca di **vulnerabilità di sicurezza**. È composto da più componenti:

| Componente        | Ruolo                                             |
| ----------------- | ------------------------------------------------- |
| **GSAD**          | Interfaccia web                                   |
| **GVMD**          | Gestore centrale delle scansioni                  |
| **ospd**          | Protocollo di comunicazione tra i componenti      |
| **Notus Scanner** | Scanner specifico per vulnerabilità nei pacchetti |
