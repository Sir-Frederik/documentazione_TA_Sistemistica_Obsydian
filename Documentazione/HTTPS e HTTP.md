### HTTP
**HTTP (HyperText Transfer Protocol)** è il **protocollo base** con cui il Browser **comunica** con un Server.
Il browser manda una richiesta HTTP al server, che risponde con una pagina HTML.
I dati di HTTP viaggiano in chiaro e chi li intercetta può leggere tutto.
Si appoggia sulla **porta** ***80***

### HTTPS
**HyperText Transfer Protocol Secure** Non è altri che il protocollo HTTP con il [[Certificati SSL E TLS |TLS]] applicato sopra.
Si appoggia sulla **porta** ***443***
